# Writing

Publications and talks.

## Publications

### MIDAS: Adaptive Proxy Middleware for Mitigating Metadata Hotspots in HPC I/O at Scale (2025)

Middleware that balances metadata load in HPC parallel file systems, cutting average queue length by about 23% in controlled experiments. I reviewed the parallel file system literature, identified the power-of-d routing approach and benchmarked the results.

Sangam Ghimire, Nigam Niraula, Nirjal Bhurtel, Paribartan Timalsina, Bishal Neupane, James Bhattarai, Sudan Jha. IEEE International Conference on Cloud Computing Technology and Science (CloudCom) 2025, pp. 1–8. [doi:10.1109/CloudCom67567.2025.11331379](https://doi.org/10.1109/CloudCom67567.2025.11331379)

### eBPF-PATROL: Protective Agent for Threat Recognition and Overreach Limitation using extended Berkeley Packet Filter in Containerized and Virtualized Environments (2025)

A runtime security agent that uses eBPF to block malicious system calls in containers and VMs with under 2.5% overhead. I proposed the idea and worked on the system architecture.

Sangam Ghimire, Nirjal Bhurtel, Roshan Sahani, Sudan Jha. National Conference on Computer Innovations (NCCI 2025). [PDF](https://ncci.ku.edu.np/uploads/archive/1770520841139-EBPF_KUSET-Sangam-Ghimire.pdf)

### Minimizing Energy Consumption in Fixed Node Networks Using a Novel Neutrosophic Model: Comparative Analysis with Standard and Existing Algorithms (2024)

A neutrosophic-logic model for minimising energy use in wireless sensor networks that outperformed six existing algorithms, including LEACH, in simulation. As corresponding author, I formulated the model, ran the simulations and did the comparative analysis.

Sangam Ghimire, Nirjal Bhurtel, Sudan Jha, Sultan Ahmad, Hikmat A. M. Abdeljaber, Jabeen Nazeer. International Journal of Information Technology. [doi:10.1007/s41870-024-02368-x](https://doi.org/10.1007/s41870-024-02368-x)

### Hybrid Approach for Enhancing Traffic Signal Control with Computer Vision and Reinforcement Learning (2023)

Adaptive traffic-signal control combining YOLOv5 vehicle detection and tracking with a PPO reinforcement-learning agent, clearing more vehicles than fixed timing in SUMO simulations, especially when lanes are imbalanced. I built the RL environment and the Unity simulation, and analysed the results against existing traffic-control practices.

Bishal Neupane, Nigam Niraula, Nirjal Bhurtel, Jenisha Khulal Magar, Pankaj Raj Dawadi. 14th International Conference on Computing Communication and Networking Technologies (ICCCNT), IEEE. [doi:10.1109/ICCCNT56998.2023.10307312](https://doi.org/10.1109/ICCCNT56998.2023.10307312)
