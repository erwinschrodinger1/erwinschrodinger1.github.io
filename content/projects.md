# Projects

A selection of things I've built. More code is available on [GitHub](https://github.com/erwinschrodinger1/).

## DJI Dock 3 deployment — Nepal Police Headquarters

Helped install and test the DJI Dock 3 for autonomous drone operations, troubleshot setup issues, and deployed a distributed container environment with GPU virtualisation.

## Project Zero Day

An open-source project to help prevent loss of life by identifying early signs of floods, including glacial lake outburst floods. The first prototype uses Sentinel-2 satellite imagery and the NDWI and MNDWI water indices to map surface water and estimate the area it covers.

[View on GitHub](https://github.com/erwinschrodinger1/project-zero-day/)

## dln2-generic

Portable firmware that makes STM32 and ESP32 microcontrollers act as USB GPIO, I²C and ADC adapters for Linux's dln2 driver, generalised from a Pico-only project into a hardware-independent core.

[View on GitHub](https://github.com/erwinschrodinger1/dln2-generic/)

## 8-bit RISC computer

An 8-bit computer based on the RISC-V architecture implemented in an FPGA using Verilog, complete with an assembler.

[View on GitHub](https://github.com/erwinschrodinger1/risc-me)

## Heat cycle and health status of cow using ML and IoT

An IoT and machine-learning system that classifies sensor readings to detect and record cattle heat cycles and health status. Built in 36 hours with ESP32/Arduino firmware streaming over WebSockets to a React and Express dashboard. I set up the ESP32 WebSockets, worked on the classifier and built the React/Express interface.

## Utopian Vision

A sustainable-planner web app that clusters OpenStreetMap data with K-Means and DBSCAN to find suitable locations for hospitals and schools, served through Django APIs and visualised in a React + Leaflet.js map interface.

[View on GitHub](https://github.com/Utopian-Vision)
